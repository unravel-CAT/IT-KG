# 阅读约定

## 深度层级

| 层 | 是什么 | 本阶段状态 |
|----|--------|------------|
| L0 | 全景与路径（本目录） | 已写 |
| L1 | 域地图（各域 `README.md`） | 已写 |
| L2 | 子域名称清单 | 列在域地图中，不单独建页 |
| L3 | 主题页（`topics/*.md`） | 目录占位，不写正文 |

先读 L0/L1 建立坐标，再按路径下钻；不要把「入门顺序」误当成目录树。

## 主题页字段（L3）

固定字段见 [_templates/topic.md](../_templates/topic.md)：

- 一句话定义  
- 主归属域  
- 参见（其他域链接，不复制提纲）  
- 不包含什么  
- 先修 / 后续  
- 分层提纲：是什么 / 为什么存在 / 怎么工作 / 再往下读什么  
- 常见混淆  
- 资料三级：入门、系统、深入  

## 资料页字段

固定字段见 [_templates/resource.md](../_templates/resource.md)：

- 类型：`book` / `site` / `blog` / `course` / `doc`  
- 作者或站点  
- 适合深度  
- 覆盖主题链接  
- 一句话为什么收它  

**同一资料只建一页**，多个主题引用同一路径。课程和官方文档与书籍、网站、博客并列，避免把权威文档塞进「博客」。

## 何时新建主题

满足多数条件再新建 L3：

1. 能用一句话定义，且不是某本书的章节标题。  
2. 去掉它，所在域的机制说明会缺一块。  
3. 能写出「不包含什么」，与邻近主题边界清楚。  
4. 至少能挂一级「入门」资料（可先链全局主档占位）。  

拿不准归属 → [inbox.md](inbox.md)。跨域规则 → [../taxonomy.md](../taxonomy.md)。

模板见 [_templates/domain.md](../_templates/domain.md)：范围、不包含什么、L2 子类、先修域、划界书（仅点名）。
