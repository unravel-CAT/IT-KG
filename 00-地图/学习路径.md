# 学习路径

路径是视图，不是目录树。正文仍按知识域存放；这里只建议阅读顺序。可与 [Teach Yourself Computer Science](https://teachyourselfcs.com/) 与 [roadmap.sh](https://roadmap.sh/) 对照，不必一一对应。

## 系统向

适合想打通「程序如何在机器上跑起来」的读者。

1. [01 计算基础](../01-计算基础/) — 信息表示与离散入门  
2. [03 计算机系统](../03-计算机系统/) — 组成、OS、网络协议栈  
3. [02 算法与数据结构](../02-算法与数据结构/) — 可与 03 交错  
4. [04 编程语言](../04-编程语言/) — 运行时与编译视角  
5. [08 基础设施与分布式](../08-基础设施与分布式/) — 部署与分布式  

参考划界材料：CSAPP；后续 DDIA / MIT 6.824。

## Web 全栈

适合面向产品与 HTTP 应用的读者。

1. [04 编程语言](../04-编程语言/) — 任选一门主力语言入门即可起步  
2. [05 软件工程](../05-软件工程/) — 版本协作、测试、交付  
3. [03 计算机系统](../03-计算机系统/) — 至少网络与进程/并发骨架  
4. [07 互联网与应用](../07-互联网与应用/) — Web、浏览器、前后端与 API  
5. [06 数据系统](../06-数据系统/) — 应用背后的持久化  

HTTP 的协议机制主归属在 03；应用语义与浏览器用法在 07。

## 数据

适合数据库、数据工程与分析方向。

1. [01 计算基础](../01-计算基础/) — 概率与线性代数中「用得上」的部分  
2. [02 算法与数据结构](../02-算法与数据结构/) — 索引与查询依赖的结构直觉  
3. [03 计算机系统](../03-计算机系统/) — 存储与并发基础  
4. [06 数据系统](../06-数据系统/) — 建模、事务、NoSQL、数据工程入门  
5. [08 基础设施与分布式](../08-基础设施与分布式/) — 与 06 互链（DDIA 两侧都要看）  

## 安全

适合工程化安全与攻防入门（不做漏洞利用手册）。

1. [03 计算机系统](../03-计算机系统/) — OS 与网络是前提  
2. [07 互联网与应用](../07-互联网与应用/) — Web 与 API 攻击面  
3. [08 基础设施与分布式](../08-基础设施与分布式/) — 身份边界、云与运行时  
4. [09 安全](../09-安全/) — 密码学应用、身份、应用与系统安全、安全工程  

## 人工智能（简表）

1. [01](../01-计算基础/) + [02](../02-算法与数据结构/) 的必要数学与算法  
2. [06 数据系统](../06-数据系统/) — 数据从哪来  
3. [10 人工智能](../10-人工智能/) — ML / DL / 大模型工程  
4. 算力与集群问题链回 [08](../08-基础设施与分布式/)  

路径有歧义或材料暂不定归属时，记入 [待归类.md](待归类.md)。
