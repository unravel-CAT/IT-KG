# IT 技术栈知识图谱

纯 Markdown 资料库：用目录与链接表达知识结构，不引入站点生成器或数据库。

**知识在前，资料在后。** 主题先写清定义与骨架，再挂书籍、网站、博客；资料有独立主档，主题页只引用。

**树是分类，路径是视图。** 正文按知识域存放；学习顺序见 [00-地图/学习路径.md](00-地图/学习路径.md)。
