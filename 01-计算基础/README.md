# 01 计算基础

## 范围

服务后面所有域的最小数学与信息表示：编码、离散结构、计算理论入门，以及直接用于 CS 的概率与线性代数片段。

## 不包含什么

- 通用数学课（分析、抽象代数整科等）不收；只收 CS 直接用到的部分。
- 具体编程语言语法 → [04 编程语言](../04-编程语言/)。
- 算法设计范式正文 → [02 算法与数据结构](../02-算法与数据结构/)。
